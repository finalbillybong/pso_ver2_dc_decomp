## Method

Batch 206 is a generator cycle over the remaining expanded candidate pool. The draft generator gained:
- **Shifts and 16-bit multiplies:** `shad`/`shld` with a constant, negated or variable count, and `muls.w`/`mulu.w`.
- **Shared-epilogue returns:** a return value moved into `r0` on the way to the epilogue is now carried into the `return`.
- **Else after a goto:** an `if` whose body ends in a jump past a following block, followed by that block, is written as `if`/`else`.
- **Compare-chain switches:** a chain of `tst`/`cmp/eq #k` + `bt` ending in `bra default` is written as a `switch` with stacked cases. Bodies follow in address order. A loop's early return with the loop's final return value is written `break`.
- **Return-order and address folding:** a second `retflip` variant, and folding of `(x + c) + d`.
- **Local pointers:** a computed address copied and offset further, or stored and then reused as a base, is a local pointer. A value loaded before a store to the same address is kept in a local from its first use.
- **Literal forms:** a literal address that matches a used global is written `&g`. Other fields at a global used as a byte base are written `*(T *)(g + off)`. A loop counter decremented in the back branch's delay slot is written `while (n--)`.
- **Element locals:** a pointer loaded from an array element and then tested and dereferenced in one `if` is named in a local first.
- **Loop variables:** in `do { ...; t = f(); } while (t == 0); v = t;` the call result is assigned to `v` inside the loop.
- **Compiler jump tables:** a bounds check followed by `shll2`, `mova` and an indexed `jmp` is a `switch`. The case values come from the table and the bounds constants. A default body is recognised among the cases or after them, and an entry that points at the join becomes `case k: break;`. An unsigned bound (`cmp/hi`/`cmp/hs`) makes the subject unsigned.

Scratch tooling changes:
- Probes and trial specs whose source contains a `switch` now use the pinned native linker (`"linker": "codewarrior"`), as the 13 previously admitted jump-table units already do. With the GNU linker the table entries lost their addends.
- The scratch comparison skips probe halfwords that are data in the reference listing, such as jump tables and pools.
- Candidate bodies that the listing review had cut short at an early `bra` were recomputed from the decoded image. This applied to 625 candidates and affects drafting only.
- The decoded spelling was checked against 902,543 listed instructions, with zero differences.

Calibration: 20/37 on batch 191 and 31/55 on batch 190, both unchanged after every rule. As a further check, the 13 admitted jump-table functions were redrafted: 7 are exact from the generator alone.

## Observed techniques

- A compiler jump table needs the native linker. The compiler emits table entries as relocations with explicit addends, which the GNU path drops.
- `case k: break;` is needed when the bounds constant reaches a value whose table entry is the join. Without it, the table is one entry shorter.
- Naming an array element in a local before testing it changes only the operand order of a later `cmp/eq`. The compiler had already shared the load.
- Assigning a retry loop's result straight to the outer variable moves the copy into the `bt/s` delay slot.
