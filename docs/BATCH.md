## Method

Batch 254 has two parts: drafts from a generator cycle with new rules, and hand-finished near misses.

**Generator rules.** A scratch pass compared 337 recently hand-finished sources with the generator's drafts for the same functions, and turned the recurring differences into generator rules. Each rule is guarded by a flag. They fall into three groups.

*Drafts that lost or changed behaviour:*
- a do-while that tests its counter before stepping it is `while (n-- != 0)`; the draft dropped one iteration;
- a value loaded by a loop's bottom test and passed by the body's call is passed, instead of an uninitialised placeholder;
- `(c = *p++)` in a loop test, where the draft passed the next byte;
- a loop counter kept in `r0` is no longer hidden by an `r0` write on an exit path;
- a switch join variable that one path leaves unchanged takes its value from before the switch;
- a function is `void` when `r0` is scratch on every return path, or when every return is a constant that the body put in `r0` as an index or compare operand;
- a draft is given a return value when all of its direct callers read `r0` after the call.

*Values the source kept in locals:*
- a word load reused across statements, with a possibly aliasing store or call in between, is a local read before its first use;
- `x * x` of one load is a local;
- a load in a conditional branch's delay slot that is used later is a local computed before the test;
- consecutive load-assigned locals are written in listing load order;
- a constant local and the loop variables are initialised in listing order.

*Source forms:*
- an unsigned-to-float conversion is stored or compared directly;
- a wrapped value is assigned straight to its short variable;
- `x << 2 << 1` is `x << 3`;
- one pool constant stored to two places is a chained assignment;
- an in-place `extu.w` before a halfword store is a `volatile` read masked with `0xffff` (CW20);
- a constant in a guard's own delay slot is set before the guard;
- `p = o; p += K` for a pool offset added to a copied base;
- a parameter copied after a guard is a block-local copy;
- a parameter advanced by a call result is updated in place;
- an unsigned narrow member compared signed gets an `(int)` cast;
- an unreachable branch to the epilogue is `else { return; }` or `case k: return;`;
- word copies that each use their own offset literal are separate member assignments;
- a float function returning a call result through `fr0` has a float callee.

One rule that made targets worse overall was removed. While the rules were developed, an intermediate version lost 16 exact drafts; each responsible rule was narrowed, and the final rules lose none.

Calibration is unchanged: 31/37 on batch 191, 44/55 on batch 190, and 8 of the 13 admitted jump-table functions. Across all 44 admitted plans (190, 191 and 211–252) and every earlier cycle's result list, in all modes, no exact draft was lost. Of the 337 hand-finished functions, the generator now drafts 208 exactly by itself, up from 156.

A redraft of the 3,701 remaining candidates in 11 modes found 134 exact drafts; 16 were new. All 16 are exact over their full reviewed range.

**Hand-finished near misses.** Three separate scratch passes took 622 candidates that no earlier pass had probed and whose best draft differed from the reference in 0–40 lines, most of them 21–40. They used the rules of batches 241–253:
- at most ten distinct hypotheses per target, counting earlier probes, with identical compiler outputs counted once;
- ordinary C or C++ only, with the pinned compiler and flags;
- full-range exact only;
- no declaration-order search.

The passes compiled 504, 199 and 244 hypotheses. The most on one target was 10, on a target that is parked. They found 118 exact sources. 117 were trialled, and the history guard refused 3, so this batch admits 114.

**Declaration-order comparisons.** The passes made labelled comparisons. Two kinds were placement checks on exact sources that gained new locals: for every admitted source checked, the other placement was also exact. The other kind decided the match; those 20 sources are held back and not trialled:
- `0x8c04c108`, `0x8c07ef4c`, `0x8c119b70`, `0x8c15b9d0`, `0x8c170c84`, `0x8c185334`, `0x8c20a608`, `0x8c22d4f0`;
- `0x8c03de60`, `0x8c05b834`, `0x8c09bac4`, `0x8c09ea64`, `0x8c09ede0`, `0x8c17e670`, `0x8c186534`, `0x8c1dc50c`, `0x8c1dc55c`, `0x8c2452b8`;
- `0x8c05b874`, `0x8c237f94`.

Also held back: `0x8c235da8`. Its pass made two declaration-order comparisons on it, against the limit of one per target, and the final source keeps an order that one of them showed to be deciding.

The history guard refused 3 attempts, on hand-finished sources for `0x8c1860ac`, `0x8c03153c` and `0x8c1190b8`, because those targets carry recorded history that the new attempt does not address. They stay blocked. Previously blocked targets stay blocked, and the three drafts held back in batch 224 remain held back.

Before admission, the boundaries of every unit were checked:
- each entry follows a literal pool (122) or a function end (8);
- no unit overlaps an admitted function or another unit;
- no branch from outside a unit lands in it;
- every entry is 4-aligned.

Signatures are provisional. Parameter and return types come from the instruction shape and literal use; they are not confirmed against callers. Identifiers are mechanical.

## Observed techniques

- Many drafts that differed by 21–40 lines had lost behaviour:
  - a dropped loop or case body;
  - an invented call or extra arguments;
  - a reset preset;
  - a doubled addition;
  - pointer arithmetic scaled by the struct size.

  Restoring the observed behaviour was usually the first step to an exact match.
- Words that look like parameter homes in a frame are often fields of a message block passed to a call.
- A field pointer taken before a switch and used by several cases is a local in the source.

## Parked and unresolved

- **Declaration order** decides register assignment in many remaining near misses. Such sources are held back, not admitted.
- **Argument-register order around a call's delay slot** and **in-place `extu.w`** remain out of scope.
- **Ranges ending in alignment padding** cannot match as units.
- **Register-only and scheduling differences** remain the largest group of near misses.

Code-only completion and total function count remain unknown.
