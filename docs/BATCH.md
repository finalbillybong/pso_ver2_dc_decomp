## Method

Batch 209 continues the cycle described in batch 207: a survey of the game code below the SDK region that no earlier candidate list covered. Entries are aligned literal words pointing into uncovered code, plus code that resumes after a literal pool. Bodies are the reachable code, and ranges run to the next known start. Drafts come from the batch 207 generator without any change.

The boundary checks from batch 207 apply to every unit here:
- each entry follows a literal pool, alignment padding, or the delay slot of a function-ending `rts`, `bra` or `jmp`;
- no branch from outside a unit lands inside it;
- no entry is referenced from a jump table.

Calibration: 20/37 on batch 191 and 31/55 on batch 190, unchanged.
