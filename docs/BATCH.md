## Method

Batch 250 comes from one generator cycle over the reviewed candidate units that the earlier drafts did not match (1,475 units, drafted in 11 modes at the reviewed ranges). The draft generator gained rules for drafts that differed from the reference in 11–20 lines, and for one argument-order family. The listing also gained instructions that it had left out.

**Delay-slot instructions the listing left out.** The listing omitted the instruction in the delay slot of 1,283 delayed branches (`rts` 720, `bra` 550, `jmp` 13), 1,091 of them inside reviewed units. Without them the drafts dropped:
- stores made in a branch's delay slot;
- `mov #0` result and loop-counter settings;
- return values set in an `rts` slot.

The slots are now decoded from the image and marked as delay slots, as the listing marks others. Functions already admitted are unaffected.

**Arguments and calls:**
- Float arguments are placed among the integer arguments by a known callee's definition. Otherwise they are placed by register evidence that CodeWarrior evaluated an integer argument first, since it evaluates arguments right to left.
- Variadic arguments after the named ones keep their own types.
- When a frame holds only parameter homes and `r15` is passed, the call takes `&aN`, and stores into the home are assignments.
- A word field passed where a known callee takes an `int` is an `int` field.
- Two or more constant arguments set in ascending argument order are each held in a local assigned just before the call. With plain literals the compiler always sets them in descending order. This applies only when the call's delay slot does not set another, non-constant argument.

**Values the source kept in locals:**
- A `mov` into a variable's register in a conditional branch's delay slot, overwritten on the fall-through path, is assigned before the `if`. The same holds for a constant set in that slot.
- A word loaded in a branch's delay slot and read on both paths becomes a local.
- A register-only expression read twice in one statement becomes a local, guarded against shared nodes, address parts and `x*x`. A repeated float difference becomes a float local.
- In a `cmp/eq` whose first operand was loaded entirely before the second, the first operand becomes a local.
- A raw halfword or byte load kept across a call becomes a narrow local.
- A local set from a word field, never dereferenced and added to another word field, is an `int`.

**Address forms and control flow:**
- A pool table address followed by `add #-k` is `(g - k) + index`.
- Base plus index, then `add #k`, then a displacement access, is member `d` of an element at `k`.
- A float member of a sub-object is reached with `add #d`, since `fmov` has no displacement form.
- An unsigned-to-float conversion is written inline when the only other uses are unused join copies.
- The top-level `if (A || B) return;` conversion is applied repeatedly.
- A read-modify-write of a frame slot is stored back.

Each rule is guarded by a flag and was narrowed wherever an earlier version lost an exact draft. While the rules were developed:
- an early switch-chain rule lost two admitted functions in two modes and was removed;
- one other rule made a target worse and was removed.

No target measured further from the reference under the final rules.

Calibration: 31/37 on batch 191 and 44/55 on batch 190 (previously 43). The 13 admitted jump-table functions: 8 exact from the generator alone, unchanged. Across the functions admitted in batches 190, 191 and 211–241 and the targets of the previous cycles, no exact draft was lost in any mode.

188 drafts were accepted, all exact over the full reviewed range. 147 of them were also finished by hand in a separate scratch pass; this batch admits the unedited generated drafts instead. The history guard refused no attempt. Previously blocked targets stay blocked, and the three drafts held back in batch 224 remain held back.

Before admission, the boundaries of every unit were checked:
- each entry follows a literal pool (169) or a function end (19);
- no unit overlaps an admitted function or another unit;
- no branch from outside a unit lands in it;
- every entry is 4-aligned.

## Observed techniques

- The listing omitted delay-slot instructions after `rts`, `bra` and `jmp` in code it had not reviewed. Drafts that dropped a store or a return value were usually missing such a slot.
- CodeWarrior sets plain literal call arguments in descending argument order. An ascending order in the reference comes from locals assigned in argument order.

## Parked and unresolved

- **Argument-register order around a call's delay slot** (a register copy in the slot while an immediate argument is set before the call) and **in-place `extu.w`** are not produced by the pinned compiler from any source form or unit context tried. Both shapes occur inside single functions alongside the usual shape.
- **Register-only and scheduling differences** remain the largest group of near misses.

Code-only completion and total function count remain unknown.
